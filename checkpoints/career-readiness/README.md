# Am I ready for the next step?

This is my reflection for the end of the GoMyCode MSC bootcamp: where I am in
my career, what the program added to it, and what I want to do next. All my
checkpoints are in this repository, so the work I talk about here is in the
folders next to this one.

## Where I was when I started

I wasn't new to software development when I joined. I already work as a
software developer, so writing code, using Git and shipping features were
things I did every day. What I didn't have was the complete picture. Like a lot
of developers who learn on the job, I knew the parts I used often very well,
and the rest I had picked up in pieces, whenever a task needed it. I joined the
program to fill those gaps properly, get stronger on the full MERN stack, and
have the computer science foundations behind the things I was already doing.

So for me the bootcamp wasn't about learning to code. It was about
understanding _why_ things work the way they do, and becoming a more complete
developer.

## What the program added for me

**The computer science I had skipped.** Algorithms and data structures
(sorting, searching, recursion, queues, graphs, Dijkstra, minimum spanning
trees), operating system concepts, networks, OOP and design patterns. At work I
rarely had to implement these myself, so going through them carefully was
probably the most valuable part of the program for me. It changed how I think
about performance, and about choosing the right structure before writing the
code.

**Databases in more depth.** I had used databases before, but here I started
from the design side: ER models, the relational model, DDL and DML,
transactions and distributed databases, then MongoDB and Mongoose. Migrating a
project from SQL to NoSQL, and benchmarking Redis against MongoDB on real
transport data (GTFS), made me think much more carefully about which database
fits which problem, instead of just using whatever the project already has.

**The full MERN stack, end to end.** React with hooks, React Router and Redux, a
TypeScript conversion, Next.js, and on the backend Node.js and Express with REST
APIs, middleware, JWT authentication and role-based permissions. Building every
layer myself, instead of only the part my team owns, gave me a much better view
of how a whole application fits together.

**Shipping complete projects on my own.** My two biggest projects are full MERN
apps that I built, tested and deployed on Microsoft Azure:

- **Kora Market**, an e-commerce store with a cart, checkout, orders, stock
  management and an admin panel. The server recalculates prices and updates
  stock safely, so the shop can't be tricked from the browser.
- **Inkwell**, a content management system with three roles (author, editor,
  admin), a draft → review → published workflow, revision history, safe
  Markdown and comment moderation.

At work, deployment and infrastructure are often handled by other people or by
pipelines that already exist. Here I had to do all of it myself: environment
variables, the database connection, the build, Azure's deployment settings,
and reading the logs when the app didn't start. That gave me more confidence
with the parts of the job that happen after the code is written.

**Soft skills.** The career checkpoints were a good reminder that communication
matters as much as code. Finding the mistakes in a CV made me look at my own
differently, and recording myself for the communication checkpoint showed me
how much pace, voice and body language change the way a message lands. That's
useful every day in meetings, code reviews and when explaining technical
decisions to people who aren't developers.

## How ready I feel

I feel ready for the next step, and for me that means growing from a developer
who is good at their part of the code into a stronger **full-stack engineer**
who can own a feature from the database design all the way to deployment. The
bootcamp gave me the foundations I was missing and the practice of building
complete systems on my own, and I'm already bringing it into my job: thinking
more carefully about data structures and queries, writing tests, and making
sure validation and permissions are checked on the server.

I still have plenty to learn, but now I know where my gaps are and how to close
them.

## What's next

- Take on more ownership at work: bigger features, system design discussions,
  and deployment and infrastructure, not only application code.
- Go deeper into testing, TypeScript, cloud services and CI/CD.
- Keep improving Kora Market and Inkwell as portfolio projects.
- Share what I learned with less experienced colleagues, because explaining
  something is the best test that you really understand it.

## Thank you

Thank you to my instructors and to GoMyCode. Doing this program alongside a
full-time developer job wasn't always easy, but it was worth it. I came in
knowing how to code, and I'm leaving with a much better understanding of what
I'm doing and why.

_Chimaroke Amadi_
